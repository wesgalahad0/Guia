Guia de Bolso

Comandos Essenciais

01 - git init

Iniciando um reposiório local

02 - git add.

Adicionar arquivos de um reposiório para o outro

03 - git commit -m "[Mensagem de Commit]"

Salva as suas mudanças para o git

04 - git push -u origin main

Altera o git na máquina local para o da nuvem

05 - git branch

Cria, lista ou exclui ramificações (branch)

06 - git fetch

Verifica se o reposiório remoto tem modificação em relação ao local

07 - git clone (link do reposiório)

Baixa um reposiório do GitHub da nuvem para o PC local. Copia o projeto

08 - git reomote add origin

Conecta o repositório local ao repositório remoto

Dica: Sempre lembre a ordem dos gits e use as setas para não precisar escrever novamente
